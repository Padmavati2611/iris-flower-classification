# Iris Flower Classification 

## Project Overview

This project is a beginner-level Data Science and Machine Learning project that classifies Iris flower species based on flower measurements.

The model predicts whether the flower belongs to:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

using:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

---

## Machine Learning Algorithm

* K-Nearest Neighbors (KNN)

---

## Project Workflow

1. Import required libraries
2. Load Iris dataset
3. Perform data exploration
4. Visualize dataset using graphs
5. Split dataset into training and testing data
6. Train KNN classification model
7. Predict flower species
8. Evaluate model accuracy

---

## Dataset Information

The Iris dataset contains:

* 150 flower samples
* 3 flower species
* 4 numerical features

Dataset Source:
Scikit-learn built-in dataset

---

## Data Visualization

The project includes:

* Pair Plot Visualization
* Correlation Heatmap

These visualizations help understand relationships between flower features.

---

## Model Accuracy

The KNN model achieved high prediction accuracy on test data.

Accuracy formula:

Accuracy = Correct Predictions / Total Predictions
